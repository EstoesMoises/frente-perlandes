# Frente Perlandés por la Libertad

Sitio del partido (roleplay de Minecraft). Hecho con Astro.

- Datos editables: `src/data/frente.ts`
- Capturas de los carteles falsos: `src/assets/carteles/`
- Probar en local: `npm install` y `npm run dev`
- Se publica solo en GitHub Pages al hacer push a `main`.
